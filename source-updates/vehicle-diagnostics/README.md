# KisaAgent 1.0.32 차량 진단

프로필: 2024 더 뉴 아이오닉 5(PE), 84kWh, 후륜 싱글모터. 사용자 선택 프로필이며 실제 배터리 사양을 ECU에서 자동 검증한 결과는 아닙니다.

## 연결 시험

1. 차량 정차·P단에서 ELM327을 연결하고 전원을 켭니다.
2. 폰 블루투스 설정에서 어댑터와 페어링합니다. 다른 OBD 앱의 연결은 종료합니다.
3. 기사에이전트 홈의 **아이오닉 5 진단 · C4 / OBD**를 열고 **어댑터 연결·기본 조회**를 누릅니다.
4. 근처 기기 연결 권한을 허용하고 ELM/OBD 어댑터를 고릅니다.
5. 블루투스·어댑터 응답과 표준 차량 ECU 응답을 따로 확인합니다. 실패 시 **진단 결과 파일 저장** 또는 복사를 사용합니다.

일반 Bluetooth SPP 연결만 지원합니다. BLE/Wi-Fi 전용 제품은 별도 연결부가 필요합니다. 고장코드는 저장/대기/영구 표준 OBD 서비스에 응답한 ECU 기준이며, NO DATA는 고장 없음이 아닙니다. CAN FD가 없다는 이유만으로 이 차량의 OBD 연결이 실패한다고 단정할 수 없습니다.

## 읽기 범위

- C4: `/diagnostics/vehicle` GET API에서 최신 차량·CAN·Panda·제어 상태를 읽습니다. 오래되거나 유효하지 않은 데이터는 정상으로 표시하지 않습니다. C4 코드 업데이트가 먼저 필요합니다.
- OBD: 고정된 읽기 명령만 허용합니다. 표준 ISO 15765-4, 11비트/500kbps로 확인합니다. 삭제·초기화·코딩·보안 해제·액추에이터 제어는 포함하지 않습니다.
- 배터리: `7E4` 대상으로 `220101`, `220105` 응답 원문을 수집할 수 있습니다. **84kWh 차량의 SOC/SOH/셀 전압 해석은 실차 미검증**이므로 수치를 임의로 표시하지 않습니다. 전원 전압 표시는 OBD 어댑터 측정값이고 고전압 배터리 전압이 아닙니다.
- 연결과 요청은 시간 제한이 있고 화면을 나가거나 종료를 누르면 소켓을 닫습니다. 자동 ECU 스캔·자동 재접속은 하지 않습니다.

## 소스 통합

파일 패키지는 `com.kisapilot.kisaagent`입니다. 기존 안드로이드 프로젝트에서 `VehicleDiagnosticsActivity`를 exported=false로 등록하고, `BLUETOOTH`(maxSdkVersion=30), `BLUETOOTH_CONNECT` 권한을 추가합니다. 홈 버튼에서 해당 Activity를 엽니다. C4 측 소스는 openpilot의 `openpilot/selfdrive/kisapilot/vehicle_diagnostics.py`와 `kisa_agent.py`에 있습니다.

앱 단위검사와 C4 진단 스냅샷 검사를 통과했습니다. 실물 어댑터의 차량 ECU 응답은 아직 확인하지 않았습니다. 원래 앱 프로젝트 전체와 서명 비밀정보는 포함하지 않습니다.
